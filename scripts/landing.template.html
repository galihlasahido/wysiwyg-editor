wysiwyg-editor

A modular rich-text editor inspired by CKEditor 5, aiming at a Google Docs-style editor for the web. Small core, everything is a plugin.

Try the demos View on GitHub Quick start

What this is

An open-source editor engine plus a set of ready-made features and interfaces. Use the whole ribbon-and-pages experience, or take only the engine and build your own UI. The demos below are small real pages built with the library, not mock-ups.

Quick start

Not published to npm yet: clone the repository and build it.

git clone https://github.com/galihlasahido/wysiwyg-editor
cd wysiwyg-editor
pnpm install
pnpm dev        # these demos, locally
pnpm test       # unit, accessibility and server tests
pnpm build      # the library in dist/
import { createEditor } from 'wysiwyg-editor';
import 'wysiwyg-editor/style.css';

const editor = createEditor({
  element: document.getElementById('editor'),
  content: '<p>Hello</p>',
  ribbon: true,                       // Office-style tabs (default: a compact toolbar)
  pages: { header: 'My document', footer: 'Page {page} of {pages}' },
  outline: true,
  onChange: (html) => save(html),
});

editor.execute('bold');                // every feature is a command
editor.getHTML();  editor.getMarkdown();

A plugin is an object: nodes and marks for the schema, commands, ProseMirror plugins and toolbar items.

const Highlight = {
  name: 'highlight-demo',
  marks: { mark: { parseDOM: [{ tag: 'mark' }], toDOM: () => ['mark', 0] } },
  setup(editor) { editor.registerCommand('mark', () => toggleMark(editor.schema.marks.mark)(editor.view.state, editor.view.dispatch)); },
  toolbar: [{ name: 'mark', label: 'Mark', command: 'mark' }],
};

Honest limits

  • Pagination is visual: it measures blocks in the browser and spaces them across pages, so it can differ slightly from print output. Verified in Chrome.
  • Track changes tracks inline edits inside one paragraph; structural edits apply untracked. PDF export is the browser's print dialog.
  • Some demos use stand-ins so they work offline: the AI demo uses a mock provider, collaboration runs two editors in one page.
  • Not included because they need external services: equations, a hosted file manager, an image optimiser, a hosted spell checker.
